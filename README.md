# StudentPerformanceAnalysis
EDA project on 2 Portuguese schools 
This project's objective is to relate variables contributing to students' higher grades

                      

We analyze by following a Descriptive, Diagnostic, Predictive and persepctive approach along with slight implementation of Artificial Intelligence using libraries as Pandas, NumPy, Matplotlib and Seaborn

                       

## Questions Explored
- Does study time affect academic performance
- Living environment impact on performance
- Identifying variables associating with higher grades

  
## Findings
- Higher study hours are proved to enhance performance.
- Living environment is a factor influencing performance
- G1 and G2 were strong predictors of final grade (G3).
